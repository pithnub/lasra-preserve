**Ovine Skin Preservation Simulator — LASRA practitioner learning**

This release uses the supplied official LASRA dark logo from `images/lasra-logo-dark.png`, fixes custom-card text contrast under Streamlit themes, and retains the v0.2 Evidence Explorer.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Plant recipes, approved chemicals, health and safety controls, and validated operating procedures take precedence over this teaching simulator.
